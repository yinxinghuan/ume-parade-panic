# Requirements

## 1. Overview

《UMe: Parade Panic》是一款 2–3 分钟的竖屏互动短片游戏：玩家在夏日巡游开场前点击五处失控装置，依次观看 UMe Family 的安全喜剧片段，最后帮助粉色兔子让奶茶花车准时出发。

## 2. Visual Design

- 目标尺寸为 390 × 844 CSS px，兼容 320 × 568 至 480 × 960 的手机竖屏。
- 开场是单一完整街头花车场景，只出现粉色兔子；角色脸部无遮挡，画面内道具无生成文字。
- 五个可点击异常分别是西瓜彩纸炮、黄色泡泡阀、绿色横幅摇柄、芒果色节拍器和珍珠气球扣。
- 每条支线只出现对应的一名家族成员，并通过完整场景首尾帧生成，不使用抠图拼贴。
- UI 只占顶部品牌安全区和底部五段式巡游路线；准确 Logo 使用从品牌手册提取的透明资产。
- 结尾是路边观众接到一杯无字奶茶的近景，不出现全家福。

## 3. Game Mechanics

- 初始有 5 个可点击异常，每个异常首次完成后点亮 1 个路线节点，重复观看不重复计数。
- 点击后立即进入约 5 秒视频；700 ms 后显示一句角色字幕，视频结束后尾帧停留 1,500 ms。
- 五条支线依次对应 MelonMick、LemonShark、GuacPiggy、MangoChick 和 BubblePearl，可按任意顺序观看。
- 每次首次完成会触发 8 枚彩纸粒子和双音反馈；全部完成后延迟 500 ms 显示“启动花车”主按钮。
- 高潮视频约 5 秒：粉色兔子把一根巨型吸管按回花车顶部，彩色珍珠灯依次亮起，花车安全启动。
- 高潮结束后停留 2,800 ms 再进入结尾页。
- 视频加载失败时使用对应尾帧显示 3,200 ms 后继续流程；高潮回退为 4,100 ms。
- 不设分数、生命或失败惩罚。

## 4. Controls

- 触控与鼠标：五个场景热点及高潮按钮使用 `pointerdown`，按下当帧缩放并播放短音。
- 键盘：Tab 遍历热点、声音和主按钮；Enter 或 Space 触发焦点操作。
- 声音按钮使用 `click` 切换，触控目标 48 × 48 px。
- 视频播放、尾帧停留与高潮期间锁定其他热点，避免多段媒体同时触发。

## 5. Win / Lose Conditions

- 胜利条件：首次看完 5 条支线并完成花车启动高潮。
- 游戏没有失败状态；媒体异常进入静态尾帧恢复路径。
- 结尾页显示“巡游出发”、一句总结、观众接杯特写和“再巡游一次”按钮。
- 重新开始清空本局五个路线节点并返回开场。

## 6. Sound Effects

- 点击异常：520 Hz 降至 410 Hz 的正弦短音，80 ms，峰值音量 0.10。
- 完成支线：620 Hz 与 780 Hz 三角波双音，各 70 ms，间隔 115 ms，峰值音量 0.08。
- 五段完成：520 / 660 / 830 Hz 三角波上行三音，每音 110–140 ms，峰值音量 0.09–0.10。
- 花车启动：660 / 830 / 990 Hz 的正弦与三角混合和弦，持续 380 ms，峰值音量 0.06–0.08。
- AudioContext 不可用或静音时不阻塞视觉流程。
